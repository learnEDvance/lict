this repo is an automated test harness for comparing text input and and image input(with the same text) for possible efficiency gains.
models to be tested with are on lm studio. docs here:https://lmstudio.ai/docs/developer/rest
the system is in following parts:
    1.lm harness:responsible for sending and recieving loads to model .all inputs are buffered and isolated.
    2.verifier:main verifier of all outputs and reports generation.
    3.generator:generates test data.
    4.brain:the accumulator and coordinator of tasks. main interface for human and llm for automating this test.
a test is like this:
1. a text input is generated as required. it can range from absolute gibberish to actual code. gibberish made by a simple randomizer program. till the length required. whereas the structured texts are generated by gemma-3-270m-it. output can vary in structure too! from blocks to structured code,etc.
2.the resulting text is then used to create an image. it is parsed, locations set and the image is by stitching from the95 rasterized vector images with single charectars on them. the letters will be inside the square bounding boxes, all being the same dimensions and no regard for fancy human readability. to create a block based system for easily adding text. and maintaining tests.
3.in the tests, a fresh instance of the model is initiated and provided the image with the simple goal of outputting the exact text from the input. these outputs will then act as control/benchmark against their image counterparts and other logs will be maintained.
4. the tests will happen  across different sizes, different sized models, different types of text, etc. to create a final finding for the project.
