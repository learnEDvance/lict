```bash
#!/bin/bash

for i in 1..10; do
  echo "Number: $i"
done
```

**Explanation:**

* **`#!/bin/bash`**: This is the shebang line, which tells the shell to use the `bash` interpreter to execute this script.
* **`for i in 1..10; do ... done`**:  This is a `for` loop that iterates through numbers from 1 to 10.
    * `i`:  The loop variable, which will hold the current number being processed.
    * `1..10`: This is a range (a sequence of numbers) that specifies the number of iterations to perform.  `1` represents the first number, `2` the second, and so on.
    * `do ... done`:  This is a block of code that will be executed for each iteration of the loop.
